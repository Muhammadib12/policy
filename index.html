Friio Privacy Policy

Private messaging & social chat

Effective Date: May 31, 2026

Friio is a private messaging and social chat app. This policy explains what data the app collects, why it is used, and how users can control it.

📋

Data We Collect

  • Account information: name, username, email address, profile photo, profile photo visibility, and authentication identifiers.
  • Social information: friends, follow requests, sent requests, blocked users, online status, last seen time, and typing/seen indicators.
  • Messages and media: chat messages, photos, videos, voice messages, message status, conversation metadata, and uploaded media identifiers.
  • Device and notification data: push notification token and basic technical data needed to keep messages, notifications, and realtime status working.
⚙️

How We Use Data

We use this data to create and protect accounts, show search results, deliver messages, display friends and requests, sync unread counts, show online/offline and typing status, prevent blocked users from contacting each other, and send notifications.

🤝

Sharing

We do not sell user data. Data is shared only with service providers needed to operate the app, such as database hosting, cloud media storage, authentication, and push notifications.

🎛️

User Controls

  • Update name, username, and profile photo
  • Delete profile photo or control who can see it
  • Block users, unfriend users, or cancel requests
  • Delete your account at any time
🗂️

Retention

Account, friend, and message data is kept while the account is active. Deleted accounts are removed from friend lists and related follow requests. Media may be removed according to app rules or when no longer needed.

🔒

Security

We use authenticated API requests and access controls to limit data access. Direct chat is allowed only between friends, and blocked users cannot chat.

👧

Children

Friio is not intended for children under 13.
